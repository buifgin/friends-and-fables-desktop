# RPG and CRPG glossary coverage

This is the app’s researched coverage guide for its English-to-Russian term dictionaries in `src/translation/russian-glossary.ts`, `src/translation/interface-russian.ts`, and `src/translation/translation-core.ts`. The dictionary is a curated set of recurring D&D and CRPG vocabulary, not a translation of every rule, setting, homebrew feature, item, spell, or proper name. Unknown prose and campaign-authored terms continue through the configured description translator.

The English names and rules groupings below follow the [D&D 2024 Basic Rules: Rules Glossary](https://www.dndbeyond.com/sources/dnd/br-2024/rules-glossary/) and [System Reference Document 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf). These are English primary sources. Russian wording in this app is a house translation, chosen for readable labels and consistent mechanics; it is not an official Russian localization. The older SRD terminology remains useful for legacy campaigns, while this list favors current 2024 names where the app supports them.

## Context and casing rules

Exact interface phrases take priority over isolated words. Thus `Roll Dice` is an instruction («Бросить кости»), while a standalone `Roll` heading is the noun «Бросок». `Roll Attack` is a compact control label («Бросок атаки»). In prose, specialized multiword mechanics and explicit damage constructions use protected canonical terms; ambiguous words such as `light`, `friends`, and lowercase spell-like verbs are not globally rewritten. A clear comma-separated damage list is protected as one mechanical phrase when the construction is “Resistance to … damage.”

Source capitalization is retained where the Russian output has a case-bearing initial: `Dexterity` in a bonus line becomes «Ловкости», while `dexterity` becomes «ловкости». Dice values, numeric counters, URLs, email addresses, and recognized names remain literal. Canonical multiword glossary entries are preferred to attempting automatic grammatical inflection throughout arbitrary prose. Bumping `GLOSSARY_VERSION` creates a new translation-cache namespace when canonical meanings or request markers change.

## Limits and maintenance

This guide describes coverage, not completeness. The 2024 Basic Rules and SRD are finite rules references; CRPGs and campaigns add unique systems, names, conditions, loot, quests, and homebrew. Add an entry when the source phrase is stable and unambiguous, keep ambiguous words in context-sensitive rules, and add a focused regression for every new deterministic behavior. Check for existing keys across all three dictionary sources before adding a term so a more general UI label does not silently override a specialized prose entry.
