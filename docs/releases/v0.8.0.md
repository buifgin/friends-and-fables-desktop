# Friends & Fables Desktop 0.8.0

Release date: 2026-10-28

This release brings recent settings, combat, chat, music, and performance improvements together.

- Unified global and campaign Settings with consistent scale, reliable reopening, section navigation, and preserved drafts.
- Left combat workspace and favorites, with native attack/check forms, saved corrections, and right-sidebar spell-slot access.
- Improved automatic damage completion, final Franz response handling, and consistent End Turn behavior. Automatic damage supports one attack against one target; batch attacks and unverified paths remain manual.
- Improved chat follow, removed an upward jump during message insertion, and corrected message-card shrinking when `/sp` guidance is hidden.
- Reduced repeated DOM work and added a frame-rate overlay for diagnosis.
- Moved Music to the first website-header position with expandable transport controls.

Attack and damage animations are currently smooth in live testing, although frame-rate drops still occur. Intermittent flicker and some historical Settings and rare issues need further review. This release does not claim all known issues are fixed.

Development is paused after this release; no future work is promised. The app is unofficial and has no official Friends & Fables support. Windows downloads are unsigned.
