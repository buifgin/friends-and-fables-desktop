# Friends & Fables Desktop 0.8.0

Release date: 2026-10-28

Package and tag version: `0.8.0`. This release gathers the recent settings, combat, chat, layout, music, and performance corrections into one version.

- Improve unified global and campaign Settings, including consistent scale, reliable reopening, section navigation, and preserved drafts.
- Add the left combat workspace and favorites, with native attack/check forms, saved corrections, and right-sidebar spell-slot access.
- Improve automatic damage completion and final Franz response handling, and make End Turn behavior consistent. Automatic damage remains limited to a native form with one attack and one target; batch attacks and other unverified paths remain manual.
- Fix chat follow behavior and an upward jump during new-message insertion, and make newly sent message cards shrink correctly when /sp guidance is hidden.
- Reduce repeated DOM work in chat, combat, and related UI paths. A frame-rate overlay is available for diagnosis.
- Move Music to the first website-header position and provide expandable transport controls.

Attack and damage animations are currently smooth in live testing, although frame-rate drops still occur. Intermittent flicker needs further review, and some historical Settings and rare issues have not been fully confirmed in live campaigns. This release does not claim that all known issues are fixed.

This is an unofficial community project, with no official Friends & Fables support or affiliation implied. Development is paused after this release because of subscription costs; no future work is promised.

Downloads are Linux x86_64 AppImage and Windows x64 portable EXE. Windows builds are unsigned. Automatic updates are not included.
