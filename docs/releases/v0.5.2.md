# 0.5.2 — music, themes, combat instructions, and interface hotfixes

Music now plays from the main app independently of its library window. Search a 266-track Scott Buckley catalog with source/license links and attribution, or browse downloaded audio in local folders and subfolders. The playlist and top controls provide playback, stop, next, repeat, mute, and volume. Closing the music window no longer causes a main-process exception.

Appearance adds preset palettes and saved named themes with circular color previews. Inputs and character messages have separate styles; expanded inputs use context styling and close on outside click or Escape. Outcome cards follow event styling, message bodies retain their text during brief native redraws, and both full-screen and embedded chat loading use the selected wallpaper or black fallback. Appearance/music controls stay visible when Linux menus open.

Saved `/sp` instructions support separate adventure and combat profiles, selected from the native encounter state, including numeric encounter IDs. Enter uses the working native Send button in both modes, and Shift+Enter inserts a soft break. Instruction settings, command validation, and profile switching preserve drafts and prevent duplicate submission.

Built-in Russian labels cover combat health and turn actions, ability/skill checks, context controls, Event ID, weight units, and Edit Encounter. Compound terms use natural lowercase. Optional **Hide text until translated** displays animated dots instead of unfinished English. Native editor hints render in Russian without changing ProseMirror decoration attributes, fixing an editor/translation feedback loop that could freeze the campaign.

Source, renderer assets, and tests are grouped by feature. Local development guides and agent workflow files are excluded from Git and packages.

Validation: real Linux campaign checks covered combat input, loading, health labels, and all seven app menus. Release binaries are built and tested by native Linux/Windows CI, including source and packaged-resource regression suites and the bundled Windows translation model. The release contains the Linux x86_64 AppImage, Windows x64 portable EXE, and SHA256SUMS. Linux prose translation still uses an optional local service; Windows includes its runtime and English–Russian model.
