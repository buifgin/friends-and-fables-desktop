# Friends & Fables Desktop 0.7.0

Release date: 2026-10-09

This release adds the combat workspace and improves native dice controls, translation, and Windows window controls.

- Dice and combat actions use a docked native workspace with a resizable panel, compact toolbar, and per-campaign width. Panel appearance can be customized separately.
- Dice opens campaign-local favorite checks first. All checks and Favorites use icon buttons. Add opens native check tiles with selection checkboxes; the checkbox-style Confirm icon saves favorites and Cancel discards changes. Favorite checks open the original form without rolling.
- Custom attack corrections retain native fields and local presets. The redundant top Corrections jump is removed; correction controls remain available in the form.
- Russian translation stays responsive when enabled with Dice open and when switching between Dice and Attacks. Newly revealed native checks translate immediately, including captions with repeated spaces. Attack interface labels and split native labels have improved local translation.
- Windows toolbar icons keep their native click regions in windowed and fullscreen modes.

Windows includes the English–Russian translator and model. Linux machine translation uses a separate local LibreTranslate service; interface glossary translations work locally. Settings and favorites remain in the existing user profile.

Downloads include Linux x86_64 AppImage, Windows x64 portable EXE, and SHA256SUMS. Windows builds remain unsigned. Automatic updates are not included.
