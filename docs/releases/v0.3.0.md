# Friends & Fables Desktop 0.3.0

Opening dropdown menus now keeps the visible page translated. The app previously restored English text when the website marked the background `aria-hidden` for accessibility. Neutral dropdowns, listboxes, and dialogs also follow the selected app theme, including black AMOLED menus; custom dice menu styles keep their priority.

- Add 540 D&D term names and 74 interface labels/help strings: account menus, character tabs, spellcasting, conditions, damage types, resources, class features, feats, equipment, and many spells. Translate numeric counters and character summaries locally. Specialized terms inside prose use consistent glossary names.
- Translate composer/search placeholder hints while preserving typed messages, editors, login fields, and campaign records. Technical tool-call dumps remain literal.
- Batch model requests, reduce streaming debounce and polling delays, reuse translations when React renders the same source again, and support description blocks up to 16,000 characters. New prose still depends on model/CPU speed.
- Include the translator runtime and English–Russian model in the Windows x64 portable EXE. Enable translation and it starts automatically; no Docker, Python installation, or separate model download is needed. The app owns a private loopback service and stops it when model translation is disabled or the app exits.

Linux x86_64 uses the existing separate local LibreTranslate service for machine-translated prose. Both versions include the built-in glossary. Translation starts disabled. Friends & Fables still needs internet; the included Windows model translates offline.

Validation: TypeScript, unit/client/cache/lifecycle tests, Python adapter protocol tests, and the three Electron appearance/translation/panel suites. The actual Windows Python libraries and model were also checked under Wine with synthetic text; native Windows CI checks the packaged model before publication. A signed-in campaign check remains useful for website layouts that change independently of this app.

Builds are unsigned. Downloads: Linux AppImage, Windows portable EXE, and SHA256SUMS. Glossary terminology and machine prose can still need review; original-text switching remains available.
