# Friends & Fables Desktop 0.2.1

Enabling Russian translation now translates website text even though Friends & Fables marks its document `translate="no"`. Version 0.2.0 treated this browser-wide opt-out as a reason to skip every page label and description. The explicit app toggle now overrides the document flag, while individual excluded blocks, names, editable drafts, and login fields remain protected.

- Add built-in translations for home-page navigation, character statistics, classes, alignments, and skill-check titles such as Acrobatics Check.
- Match Translation settings to the selected app theme, including AMOLED, light, and custom colors. Live theme changes preserve unsaved translation settings.
- Retain original-text switching, local cache, name/URL/dice preservation, the resizable Appearance panel, and existing appearance controls.

The local engine was verified separately with a generic sentence. Regression tests now include the real document opt-out flags, nested exclusions, game/home labels, and theme synchronization. Story translation still uses a separate local LibreTranslate service; see [setup](../TRANSLATION.md). These builds are unsigned and are not published automatically.
