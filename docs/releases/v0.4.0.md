# Friends & Fables Desktop 0.4.0

Commands now format only their own line, shared Russian interface wording is more consistent, and the pinned Appearance button has its own toolbar space on Windows.

- Enable `/me` and `/gm` in Appearance → App. `/me` makes its line italic; `/gm` wraps its line in `#` marks. Enter or Shift+Enter formats the current command line and starts a plain new paragraph. Format command, Ctrl+Enter, or the first Send click prepares command lines independently for review. Mentions, links, code, and other lines retain their formatting.
- Expand the fixed Russian dictionary to over 2,300 entries, including character creation/sheets, equipment slots, currencies, dice bonuses, campaign settings, account menus, and common editor controls. Use **КБ / Класс брони**, **Умение / Бонус умения**, and **Франц** consistently. Model names such as Gemini 3.1 Pro retain their official spelling. Fixed UI copy works without the translation service; new prose still depends on the local model. Opening dropdowns keeps the surrounding interface translated.
- Translate the top application menus and their commands alongside the Translation switch. Showing originals returns both menus and page text to English.
- Prevent the pinned Appearance launcher from overlapping website avatars or navigation on Windows, including fullscreen. Opening the resizable panel keeps the game beside it; unpinning restores the full game area.
- Add independent natural-20 and natural-1 D20 face, edge, and number colors, with previews, saved preferences, reset/undo, and theme import/export.
- Resize the campaign map vertically or expand it above the game with resizing in both directions. Sizes are remembered per campaign; keyboard resizing, reset, and Escape are supported.

Windows x64 includes the translator runtime and English–Russian model. Linux x86_64 continues to use a separate local LibreTranslate service for machine-translated prose. Both builds contain the fixed glossary. Translation and message commands start disabled.

Validation covers TypeScript, unit/cache/client/lifecycle checks, translator protocol tests, and offline Electron suites for appearance, translation, menus/panel placement, map resizing, and real Tiptap command formatting. Native Linux/Windows CI also checks packaged resources and the included Windows model before publication. Signed-in campaign layouts can change independently of this wrapper and may still need additional translations.

Downloads: Linux AppImage, Windows portable EXE, and SHA256SUMS.
