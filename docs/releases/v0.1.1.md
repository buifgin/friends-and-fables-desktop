# Friends & Fables Desktop 0.1.1

Customize each gradient color’s opacity independently and adjust the proportion of each color on messages,
inputs, context surfaces, movement/action cards, and dice cards. Existing themes
keep their current appearance until these controls are changed.

Choose a separate color for the calculation, success/failure, and damage text
beneath dice. This works independently of roll-card and SVG dice colors.

- Toggle fullscreen with Alt+Enter, numpad Alt+Enter, or F11 on Linux and Windows.
- Use black Linux dropdown menus with enough room for every option in windowed and fullscreen views.
- Keep the Linux website view fitted to the window when entering/leaving fullscreen.
- Import WebP pictures directly or browse them in a remembered folder. They are
  stored as PNG, preserving transparency; animated pictures import as stills.
- Keep the full local reference folder out of Git and packaged ZIPs; use small
  sample fixtures for regression tests.
- Prepare GitHub Actions checks, native Linux/Windows builds, packaged-resource
  tests, and version-specific SHA256 checksums.

The release remains unsigned. The v0.1.0 builds were tested by the user on Arch
and Windows. These new builds need a manual campaign check on both systems before
publication. Russian translation is the next milestone.
