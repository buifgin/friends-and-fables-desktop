# Friends & Fables Desktop 0.2.0

Read displayed English website text in Russian through the new Translation menu. Translation starts disabled; enabling it uses a built-in interface/game dictionary and an optional local LibreTranslate service for descriptions and story text.

- Preserve Russian passages, listed names, URLs, and dice notation.
- Switch back to original text without a reload.
- Keep editable drafts, event records, element structure, and button handlers unchanged.
- Translate late and streaming content, ignoring stale results.
- Cache model translations locally across restarts and continue using the dictionary/cache if the service stops.
- Configure a loopback-only service, check model readiness, and clear the cache in a separate local settings window.
- Sync the Appearance editor to the app theme, with readable light and custom palettes.
- Pin Appearance as an interface button opening a resizable left panel in the existing window, including fullscreen; remember its width.
- Use built-in Russian labels for Appearance, its panel/button/dialogs, and Translation settings when translation is enabled.
- Retain the corrected black Linux dropdowns, per-color gradient opacity, fullscreen shortcuts, and all other appearance features.

The model is a separate service in this prototype, including on Windows. See [setup and measured results](../TRANSLATION.md). Machine prose can contain errors; use Show original text to verify uncertain passages. Docker-free model distribution remains a later step. Builds are unsigned and publication remains manual.
