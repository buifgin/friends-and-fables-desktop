# Friends & Fables Desktop 0.7.2.7

Release date: 2026-10-12

This release brings settings together, adds more appearance and dice controls, and improves the desktop toolbar and campaign panels.

- Open Settings from the gear on the website's left side to manage Campaign, Appearance, Translation, /sp, Music, Combat, and General settings in one place. Music settings are reserved for future options.
- Customize the left panel's background, opacity, borders, button colors, spacing, and transparency. Favorites use a two-column category layout that shows only categories with selected favorite checks.
- Correct attack-roll ability and bonuses before submitting a form. Ability, modifier, and proficiency adjustments are available; advantage, disadvantage, and normal mode affect only the current roll. Defaults apply to a character in the current campaign, with separate weapon and spell defaults. Save here, delete a specific default to fall back to the general one, save a general default, or overwrite defaults across all characters.
- Attack-roll spells use the attack correction flow without changing damage rolls. Spell-slot borders can be shown or hidden, and native clicks restore the right character sidebar.
- The music shortcut sits beside the header background and grouping controls, before the avatar row. It has a circular close control and settings in the footer; the header supports up to six avatars.
- Long names wrap more cleanly, labels align better, and the right panel, map, and gutter handle scrolling and layout more reliably.
- Use Alt+Enter or F11 for fullscreen and Ctrl+Shift+B to show or hide the desktop top bar. A General setting can keep the top bar hidden in fullscreen.
- Combat settings offer two campaign-local options, both off by default: automatically accept the native damage prompt after your own confirmed hit, and optionally hide only that hit's linked intermediate Franz response. Automation handles one attack against one target; batches remain manual, misses are not automated, and critical damage follows the native prompt. Hiding the intermediate response still allows Franz to generate it, which may spend credits and affect context; final and unrelated responses remain visible.
- Startup and window lifecycle handling is more reliable.

Windows includes the English–Russian translation model. Linux machine translation continues to use a separate local LibreTranslate service. Downloads are Linux x86_64 AppImage and Windows x64 portable EXE, with SHA256SUMS. Windows builds remain unsigned; automatic updates are not included.
