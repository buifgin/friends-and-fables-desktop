# Friends & Fables Desktop 0.5.0

Shift+Enter now inserts a soft line break without large paragraph gaps. `/me` and `/gm` formatting stays on the current line, and the next line starts without inherited italics.

Translation displays completed sentences progressively instead of waiting for an entire long page. Small batches share work across paragraphs and prioritize visible text. A progress badge and dotted block marks show pending translation. Cached and glossary text remains immediate; uncached prose still depends on local CPU/model speed.

Russian localization now covers victory/defeat summaries, ally/enemy badges, battle duration, damage/healing/movement tooltips, inventory event verbs, and sorcerer progression headings. Ability and draconic spell names retain consistent glossary translations inside descriptions. AC remains «КБ / Класс брони», Proficiency remains «Умение», and Franz remains «Франц». Campaign-specific names keep their spelling.

Expanded maps can be dragged using **Move map**, or moved with arrow keys (Shift for larger steps; Home to center). World maps now support height resizing, expansion, and resizing both dimensions. Battle/world map sizes and positions are saved separately for each campaign, with viewport bounds, Reset, and Escape. Enable **Resizable campaign map** in Appearance → App.

Downloads:

- Windows x64 portable EXE includes the local English–Russian translator and model. No separate translator installation is required.
- Linux x86_64 AppImage retains the separate LibreTranslate setup; Linux translator bundling remains deferred.
- SHA256SUMS verifies both downloads.

Validation: TypeScript, glossary/client/cache tests, real Tiptap soft-break tests, incremental translation and restoration tests, and Electron appearance, panel, map resize/movement tests. Native Linux and Windows builds passed the packaged-resource tests; Windows also passed the real included-model check. Map selectors follow the saved shared website component structure; a signed-in live campaign check is still useful because the website can change independently.

Build verification: [native Linux and Windows CI](https://github.com/buifgin/friends-and-fables-desktop/actions/runs/36866728604).
