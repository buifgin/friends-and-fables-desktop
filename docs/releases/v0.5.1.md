# 0.5.1 — interface and composer hotfix

Common menus and settings now use built-in Russian translations: campaign and discovery lists, workshop categories, image studio controls, profile/account/notification settings, credit history, the sidebar account menu, and campaign navigation tooltips. Context headings/counts and split stat-adjustment labels are translated locally. Character-length counters say «символов» and retain the closing parenthesis. Composer placeholders are translated without changing drafts. Email addresses retain their original spelling.

Progress dots underline only untranslated sentence ranges. Translated text and protected names/addresses remain clear. Decorative input borders retain the website's search-icon padding, and the sidebar account tile follows the selected theme.

With message commands enabled, Enter or Send formats every command line, converts `№` to `#` outside code, checks the draft, waits for the editor state update, and submits once through the normal Send button. Empty commands block submission; editing a queued draft cancels it. Shift+Enter keeps soft breaks without extra paragraph spacing. The centered Format command hint still supports review without sending.

Windows includes the local English → Russian translator. Linux keeps its existing optional loopback translator setup. Campaign prose can still need model translation; common interface labels do not.

Validation: TypeScript, unit/protocol tests, and Electron regression suites for appearance, translation, the settings panel, campaign maps, and the real Tiptap composer. Native Windows/Linux source and packaged-resource checks passed, including the bundled Windows translator model. The release includes the Windows x64 portable EXE, Linux x86_64 AppImage, and SHA256SUMS.
