First public release of the unofficial Friends & Fables desktop app.

- Linux x86_64: download the AppImage, make it executable, and run it. Arch Linux / Wayland / Hyprland is the primary Linux target.
- Windows x64: download and run the portable EXE. No Node.js or installation is needed. This build is unsigned and still needs a manual check on Windows.
- SHA256SUMS contains SHA-256 checksums for both downloads.

Includes persistent website login, zoom shortcuts, black Linux menus, appearance presets, custom chat pictures and a permanent folder browser, image blur/opacity/overlay, player and GM styles, separate context surfaces, decorated message/event/dice borders, custom dice colors, theme sharing, reset undo, and floating Appearance on Hyprland.

Linux packaged behavior has offline Electron checks. Live campaign checks remain useful because website changes can affect styling selectors. Translation and automatic updates are planned for later releases. Friends & Fables requires internet access.

The wrapper is MIT licensed and is independent of the Friends & Fables service.
