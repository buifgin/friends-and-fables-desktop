# Roadmap

## Current status

Version 0.8.0 is the latest release. Development is paused, and no future work is promised.

The release includes unified Settings, appearance and translation options, music playback, campaign map sizing, combat workspace and favorites, combat corrections, chat-follow improvements, and reduced repeated DOM work. See the [release notes](releases/v0.8.0.md) for details.

## Known issues

- Frame-rate drops still occur, although attack and damage animations are currently smooth in live testing.
- Intermittent flicker needs further review.
- Some historical Settings behavior and rare issues have not been fully confirmed in live campaigns.

These are known limits, not promises of future fixes. Detailed implementation history and earlier verification records remain in the versioned release notes and project guides.
